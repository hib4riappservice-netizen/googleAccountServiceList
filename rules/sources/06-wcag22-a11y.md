# WCAG 2.2

出典: https://www.w3.org/TR/WCAG22/ （W3C勧告、2023年10月）

WCAG 2.2 は全 **86** の達成基準からなる（2.1 から **9基準を追加**し、
**4.1.1 Parsing を削除**（Obsolete and removed）したため、78 + 9 − 1 = 86）。
本プロジェクトは **レベルAA準拠** を目標にする（世界的にも日本のJIS X 8341-3:2016でも実務上の基準線）。

## WCAG 2.2 で追加された9基準

| 達成基準 | レベル | 内容 |
|---|---|---|
| 3.2.6 Consistent Help | A | ヘルプ機能を複数ページで一貫した位置に置く |
| 3.3.7 Redundant Entry | A | 同一プロセス内で同じ情報を再入力させない（自動補完 or 選択可能に） |
| 2.4.11 Focus Not Obscured (Minimum) | **AA** | フォーカスされた要素が、固定ヘッダやポップアップに**完全に隠されない** |
| 2.5.7 Dragging Movements | **AA** | ドラッグ操作に、ドラッグを使わない代替手段を用意する |
| 2.5.8 Target Size (Minimum) | **AA** | クリック/タップ対象は **24×24 CSSピクセル以上**。十分な間隔があれば例外あり |
| 3.3.8 Accessible Authentication (Minimum) | **AA** | 認知機能テスト（パズル、記憶）を認証の必須手順にしない。**パスワードマネージャの貼り付けを妨げない** |
| 2.4.12 Focus Not Obscured (Enhanced) | AAA | フォーカス表示が完全に見えている |
| 2.4.13 Focus Appearance | AAA | フォーカスインジケータは2px以上の外周、フォーカス前後で3:1以上のコントラスト |
| 3.3.9 Accessible Authentication (Enhanced) | AAA | 上記のより厳しい版 |

## 個人開発で特に踏みやすい地雷（AA基準）

- **sticky header にフォーカスされた要素が隠れる**（2.4.11）── Tabキーで全画面を通してみれば分かる
- **アイコンボタンが小さすぎる**（2.5.8）── 24×24px 未満のタップ領域
- **`outline: none` でフォーカスリングを消す**（2.4.7 Focus Visible / AA、2.1からの既存基準）
- **ドラッグ&ドロップ並べ替えに代替手段がない**（2.5.7）
- **独自CAPTCHAやパズル認証**（3.3.8）

## 既存の重要なAA基準（2.1以前から）

- 1.4.3 Contrast (Minimum): 本文テキスト **4.5:1**、大きな文字 3:1
- 1.4.11 Non-text Contrast: UIコンポーネント・グラフィックの境界 **3:1**
- 2.1.1 Keyboard: すべての機能がキーボードで操作可能
- 2.4.7 Focus Visible: フォーカスが視覚的に分かる
- 4.1.2 Name, Role, Value: UIコンポーネントに名前・役割・状態がある
- 1.3.1 Info and Relationships: 見た目でなくマークアップで構造を表現する
