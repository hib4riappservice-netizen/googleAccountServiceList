# 日本のウェブアクセシビリティ（JIS X 8341-3 / デジタル庁）

## 規格の関係

- **JIS X 8341-3:2016** — 日本のウェブアクセシビリティ規格。**WCAG 2.0 と一致規格**（ISO/IEC 40500:2012 = WCAG 2.0）。
- **WCAG 2.2** — W3C勧告（2023年10月）。JISのベースとなっている国際標準の最新版。
- 日本では「JIS X 8341-3:2016 の**レベルAAに準拠**」という表現が公的機関・企業で使われる。
- WCAG 2.1 / 2.2 は 2.0 の上位互換なので、**WCAG 2.2 AA を満たせば JIS X 8341-3:2016 AA も満たす**。

出典: https://waic.jp/guideline/ （ウェブアクセシビリティ基盤委員会 WAIC）

## デジタル庁「ウェブアクセシビリティ導入ガイドブック」

出典: https://www.digital.go.jp/resources/introduction-to-web-accessibility-guidebook

- JIS X 8341-3:2016 準拠を実現するための具体的な方法と事例を示した公的ガイド。
- スマートフォン対応、**SPA（シングルページアプリケーション）** といった現代的な課題も扱っている
  （SPAでのフォーカス管理・ページ遷移のアナウンスなど、Next.js App Router で直接効く）。
- 中小規模の事業者でも段階的に取り組めるよう、優先順位づけの考え方が示されている。

## 法的位置づけ（重要）

- **障害者差別解消法**の改正により、**2024年4月1日から民間事業者にも「合理的配慮の提供」が法的義務**となった。
- ただし「ウェブアクセシビリティ（JIS準拠）そのもの」が民間に義務付けられているわけではない。
  義務なのは合理的配慮の提供であり、アクセシビリティ確保は**環境の整備（努力義務）**に位置づけられる。
- 実務上の結論: **個人開発でも AA を目標に置き、最低限「キーボード操作・コントラスト・フォーム
  ラベル・代替テキスト」は落とさない**。この4つは事故率が高く、修正コストも低い。

## 個人開発での現実的な適用ライン

| 優先度 | 項目 | 理由 |
|---|---|---|
| 必須 | キーボードだけで主要導線を完走できる | 実装コストが低く、壊れていると使えない人が出る |
| 必須 | フォーム項目に `<label>` が紐づいている | スクリーンリーダーで致命的。修正も容易 |
| 必須 | 意味のある画像に代替テキスト、装飾画像は `alt=""` | 同上 |
| 必須 | テキストコントラスト 4.5:1 以上 | デザイン段階で決まるので後から高コスト |
| 推奨 | SPA遷移時のフォーカス移動とページタイトル更新 | App Routerで壊れやすい |
| 推奨 | タップ対象 24×24px 以上 | WCAG 2.2 AA |
| 推奨 | フォーカスリングを消さない / 隠さない | sticky headerに注意 |
