# 個人情報の運用（JP-02）

`rules/50-japan-compliance.md` JP-02に基づく。アカウント削除時にデータがどうなるかを明確にする。

## 現状（Googleサインインのみ）

本サービスはデータベースを持たない。Googleサインインで取得する氏名・メールアドレス・
プロフィール画像は、Auth.jsの暗号化JWTセッション（HttpOnlyのブラウザCookie）にのみ存在する。

- **削除の実行方法**: サインアウトすると即座に消える（Cookieが失効する）。
  加えてセッション自体も一定期間で自動失効する。
- **バックアップへの残留**: 発生しない。DBを持たないため、DBのバックアップという概念自体がない。
- **本サービス側からGoogleへのアクセス権を取り消す方法**: 利用者は
  [Googleアカウントのアプリ許可設定](https://myaccount.google.com/permissions) から、
  本サービスへのアクセス権自体をいつでも取り消せる。取り消すと次回以降サインインできなくなる。
- **「アカウント削除」導線を別途用意していない理由**: 本サービス側にサーバー保存された
  アカウント/データが存在しないため、削除すべき対象がない。サインアウト＋Google側の
  アプリ許可取り消しで実質的に完了する。

## 見直し条件

Gmail走査機能（別spec）や、何らかのデータをサーバー側に保存する機能を追加したら、
このファイルを更新し、保存する情報ごとに削除方法・バックアップの扱いを追記する。
